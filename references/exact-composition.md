# 精确拼合

当宿主允许脚本图像处理、能取得原图文件、并有 Python 与 Pillow 时使用。裁切和照片复制由脚本完成，AI 负责观察照片、选择裁切与线稿路径、撰写文案。该路线不依赖任何图片生成服务。

## 操作

1. 查看原图，并确认 EXIF 旋转后的朝向。配置中的裁切坐标对应**校正方向后的图像**。
2. 自动选出标题、两行短诗、五行注记、日期和次要线稿。将配置写入临时工作目录。用户无需编写配置。
3. 使用宿主提供的 Python 调用脚本。缺少 Pillow 时先遵从宿主依赖管理规则，不自动修改全局环境。
4. 查看输出 PNG，确认线稿确实对应原照、文字不挤压、裁切合理。根据实际问题调整配置并重跑。

```text
python scripts/compose_zine.py --image SOURCE --config CONFIG --output RESULT.png
```

可选：`--width 1200`；默认宽 1536、高 2048。宽度须为 6 的倍数，使高度为整数且上下能严格等高。`--font /path/to/serif.ttf` 可指定宿主上真实存在的衬线字体；不要将系统字体复制到分发包里。

## 配置

以下仅展示配置结构与措辞长度，不是给所有图片固定使用的文案或线稿。智能体须依据当前照片重写。示例线稿只适用于照片里实际存在相应轮廓的情况。

```json
{
  "date": "10. 28. 2026",
  "title": "A Quiet Interval",
  "poem_lines": [
    "The afternoon waits where",
    "our unfinished thoughts grow still."
  ],
  "micro_lines": [
    "field notes",
    "collected light",
    "paper study",
    "a passing hour",
    "image fragment"
  ],
  "sketch_paths": [
    [[0.08, 0.76], [0.44, 0.16], [0.86, 0.73]],
    [[0.19, 0.65], [0.19, 0.91], [0.73, 0.91], [0.73, 0.63]]
  ]
}
```

- `date` 为最终展示日期，不可照抄示例日期。优先用用户日期、可靠拍摄时间，再用用户当地当前日期。
- `title` 为 2–3 个英文词。
- `poem_lines` 必须两行，合计 8–12 个英文词。
- `micro_lines` 必须五行，每行宜 1–5 个词。
- `sketch_paths` 为一条或数条折线路径。每条至少两个 `[x,y]` 点，归一化到线稿小区域的 0–1 范围；用极少线条描述原照中的次要元素。路径无需闭合，避免图标式规整。
- 可选 `crop_box: [left, top, right, bottom]`：在校正方向后的原图中，归一化到 0–1 的裁切边界。脚本在此范围内等比填满上部，必要时再做居中裁切，不拉伸。省略时对完整原图做居中 cover 裁切。为突出中心兴趣点，优先由 AI 明确给出合理边界。

## 真实保真范围

精确指的是：上部照片经过一次裁切、等比缩放后，下邮票**直接复制这个已排版图像中上孔所在的像素**。孔洞与邮票使用同一个抗锯齿齿孔掩模。下邮票的完全不透明像素与挖出前该区域逐像素一致，原照在孔洞外不加滤镜。

这不代表整张成品与原文件尺寸、编码或所有像素完全相同；裁切与缩放本身会产生采样。也不证明语义裁切和线稿选择正确，它们仍需智能体实际看图判断。

脚本在保存后重新读取 PNG，检查照片外露区域、孔洞、下邮票与共享掩模的关系，通过才返回成功。禁止在其后加覆盖全图的噪点、滤镜或生成式重绘，否则该像素校验失效。
